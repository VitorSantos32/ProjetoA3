📊 ProjetoA3 - Dashboard de Análise de Dados Médicos
HTML5CSS3JavaScriptChart.jsVercel

Uma aplicação robusta de análise de dados voltada para a área da saúde, focada na visualização de consultas médicas da região Nordeste do Brasil (baseada em dados de 2003). O projeto utiliza processamento direto de planilhas Excel no navegador para gerar insights visuais claros e interativos.

🚀 Funcionalidades
📂 Processamento de Excel (XLSX): Leitura e extração de dados diretamente de arquivos Excel usando a biblioteca SheetJS.
📊 Gráficos Interativos: Visualização dinâmica de dados populacionais e consultas médicas através do Chart.js.
📱 Interface Responsivo: Dashboard otimizado para diferentes resoluções de tela.
⚡ Deploy Contínuo: Configurado para hospedagem rápida e estável na Vercel.
🔔 Gestão de Estados: Tratamento visual para carregamento (loading), sucesso e erros de leitura de dados.
🛠️ Tecnologias Utilizadas
HTML5 & CSS3: Estrutura e estilização moderna com sistema de grids e flexbox.
JavaScript (ES6+): Lógica de manipulação de dados e controle do DOM.
Chart.js: Renderização de gráficos de alta performance.
SheetJS (XLSX): Biblioteca para parse e leitura de arquivos .xlsx.
Font Awesome: Conjunto de ícones profissionais.
